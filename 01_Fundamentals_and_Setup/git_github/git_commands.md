
# Git and GitHub Commands

| Command                 | Purpose                              |
|-------------------------|--------------------------------------|
| git init                | Initialize a Git repository          |
| git status              | Check working tree status            |
| git add filename        | Stage a specific file                |
| git add .               | Stage current directory changes      |
| git commit -m "message" | Save staged changes in local history |
| git log --oneline       | View commit history                  |
| git diff                | View unstaged changes                |
| git push                | Upload local commits to GitHub       |
| git pull                | Fetch and integrate remote changes   |

## Standard Workflow
1. Modify project files.
2. Run git status.
3. Stage intended changes with git add.
4. Commit using git commit.
5. Upload using git push.
6. Verify changes on GitHub.

## Security Reminder
Never commit API keys, passwords, tokens,
or other confidential information.
